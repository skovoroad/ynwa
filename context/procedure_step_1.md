# Шаг 1: постановка задачи

Этот шаг выполняет человек. ИИ-ассистент участвует как собеседник и помощник при редактировании.
В папке с названием task_<номер_задачи>_<говорящий_текстовый_идентификатор> создаётся файл под названием task.md
Создаётся ветка с тем же названием.
В файле task.md в свободной форме описывается задача
DOD - git переведён на ветку с задачей. в папке задачи лежит файл task.md, в нём описана задача. он закоммичен.
