# Шаг 5: ревью 

Этот шаг выполняют ИИ-ассистент. 
DOR: 
- в папке с задачей есть файл task.md с постановкой задачи и архитектурным решением по ней.
- в файле task.md есть отметка, что решение заапрувлено.
- git переключен на ветку задачи.
- закоммичен код, решающий задачу
- начат НОВЫЙ диалог с ИИ-ассистентом

На этом шаге ИИ-ассистент проводит ревью закоммиченного решения.
- ИИ-ассистент читает файл context/context.md для ознакомления с проектом.
- ИИ-ассистент читает файл task.md из папки задачи.
- ИИ-ассистент читает дополнительную документацию, если это надо.
- ИИ-ассистент проводит ревью закоммиченного решения. Следует проверять как программное решение, так и соответствие решения заданию. Для получения правок он сравнивает ветку с веткой master. В числе прочего, при ревью следует руководствоваться context/code_requirements.md. Если есть замечания, ни пишутся в файл review.md, файл коммитится. 
- Если замечания несущественные, то они правятся сразу по согласованию с человеком. Если замечания существенные, то человек перейдёт к шагу 4. Существенность комментария определяется ИИ-ассистентом и подтверждается человеком.

DOD: одно из двух: код исправлен, согласован человеком, закоммичен, либо создан файл review.md с замечаниями и закоммичен уже он.
