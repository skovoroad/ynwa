# Шаг 3: ревью архитектурного решения

Этот шаг выполняют ИИ-ассистент и человек. 
DOR: 
- в папке с задачей есть файл task.md с постановкой задачи и архитектурным решением по ней.
- git переключен на ветку задачи.
- начат НОВЫЙ диалог с ИИ-ассистентом

На этой стадии не пишется код. Производится ревью архитектурного решения для задачи.
Порядок работы:
- ИИ-ассистент читает файл context/context.md для ознакомления с проектом.
- ИИ-ассистент читает файл task.md из папки задачи.
- ИИ-ассистент читает дополнительную документацию, если это надо.
- ИИ-ассистент проводит ревью описанного в файле task.md решения и выводит результаты своего анализа.
- Если замечания незначительные, они исправляются по согласованию с человеком. В файле task.md ставится отметка, что ревью пройдено.
- Если замечания значительные, они записываются в файл arch_review.md и коммитятся. После этого человек вернётся к шагу 2.

DOD: одно из двух: или в файле task.md ставится отметка, что ревью пройдено и архитектурное решение согласовано, либо в папке задачи создан файл arch_review.md с замечаниями. Файл закоммичен.
