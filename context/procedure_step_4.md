# Шаг 4: кодирование 

Этот шаг выполняют ИИ-ассистент и человек. 
DOR: 
- в папке с задачей есть файл task.md с постановкой задачи и архитектурным решением по ней.
- в файле task.md есть отметка, что решение заапрувлено.
- git переключен на ветку задачи.
- начат НОВЫЙ диалог с ИИ-ассистентом

На этой стадии пишется код. 
- ИИ-ассистент читает файл context/context.md для ознакомления с проектом.
- ИИ-ассистент читает файл task.md из папки задачи.
- ИИ-ассистент читает дополнительную документацию, если это надо.
- Если код уже написан и проревьюирован (в папке задачи есть файл review.md), то ИИ-ассистент исправляет написанный код на основании замечаний из  review.md из папки задачи. Файл review.md удаляется (он всё равно есть в истории гита)
- Если код по задаче ещё не написан, ИИ-ассистент пишет код на основании архитектурного решения и требований к коду, описанных ниже.
- Человек проводит ревью, ИИ-ассистент исправляет.
- ИИ-ассистент добивается выполнения тестов.
- Итоговый вариант коммитится в ветку. 

Требования к коду смотри в context/code_requirements.md

DOD: код написан, согласован человеком, закоммичен.
