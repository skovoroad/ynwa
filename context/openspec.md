# План перехода на openspec

1. перевод документации по проекту, а также существующих задач на английский язык. 
2. установка openspec 
    npm install -g openspec
    openspec --version
3. инициализация openspec:
    openspec init
4. адаптация для zed:
При инициализации 
  openspec init --tools github-copilot 
возьмите сгенерированные файлы из папки .github/prompts, скопируйте их в директорию .zed/prompts,или .rules, в зависимости от настроек вашего воркспейса, и адаптируйте под вызов через символ @, например, @opsx-propose.
- Создайте директорию в корне репозитория: mkdir -p .zed/prompts
- Скопируйте файлы из сгенерированной OpenSpec папки .github/prompts/ (если вы инициализировали с флагом copilot) в .zed/prompts/.
- Переименуйте файлы для удобства. Имя файла станет именем команды. Например, переименуйте propose.md в opsx-propose.md.
- Теперь в панели чата Zed Agent при вводе / появится выпадающее меню, в котором будет команда /opsx-propose. При ее выборе Zed вставит содержимое Markdown-файла в контекст промпта.
5. Заполнение project.md:
- Фиксация требований к архитектурным решениям и код-стайлу
- Фиксация ссылок на документацию
- Требование: в диалогах используется русский язык, но в документации английский
6. Написать памятку для разработчика по командам openspec
7. попробовать тестовую задачу из существующих задач по полному процессу, каждый этап в новом диалоге:
- opsx:explore
- opsx:propose
- opsx:apply
- opsx:verify
- opsx:archive
8. удалить лишнюю документацию: документация и задачи на русском языке, а также устаревшее описание процедура работы над проектом, чтобы агент не путался
