# Шаг 3 c половиной, дополнительный.

Этот шаг выполняют ИИ-ассистент и человек. Он выполняется не всегда, опционально, по решению человека.
DOR: 
- в папке с задачей есть файл task.md с постановкой задачи и утверждённым архитектурным решением по ней.
- git переключен на ветку задачи.
- начат НОВЫЙ диалог с ИИ-ассистентом

На этой стадии не пишется код. Производится декомпозиция архитектурного решения на этапы.
Порядок работы:
- ИИ-ассистент читает файл context/context.md для ознакомления с проектом.
- ИИ-ассистент читает файл task.md из папки задачи.
- ИИ-ассистент читает дополнительную документацию, если это надо.
- ИИ-ассистент декомпозирует решение на отдельные этапы, каждый этап - законченный компилируемый и семантически связанный фрагмент кода, который может стать коммитом. Цель декомпозиции - разбить слишком большие задачи на куски, доступные ревьюированию. Декомпозированный список этапов вносится в task.md
- После обсуждения и согласования с человеком файл коммитится.

DOD: декомпозиция произведена, внесена в task.md, согласована с человеком, закоммичен.
