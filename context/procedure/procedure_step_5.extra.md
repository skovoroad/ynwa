# Шаг 3 c половиной, дополнительный.

Этот шаг выполняют ИИ-ассистент.
Он выполняется не всегда, опционально, по решению человека.
DOR: 
- в папке с задачей есть файл task.md с постановкой задачи и утверждённым архитектурным решением по ней.
- git переключен на ветку задачи.
- кодирование по задаче завершено
- начат НОВЫЙ диалог с ИИ-ассистентом

На этой стадии проверяется тестовое покрытие.
- проверяется, что новые тесты покрывают новый код, все пути. 
- для каждого нового теста проверяется его работоспособность методом мутационного тестирования: агент вносит временные правки, которые портят код в части, проверяемой тестом. Тест должен упасть! Эта проверка проводится для всех путей.
- если найдены проблемы, они записываются в файл review.md, человек принимает решение о возвращении к кодированию (шаг 3).

DOD: одно из двух: либо ИИ-ассистент рапортует об отсутствии проблем, либо создан файл review.md с замечаниями.
