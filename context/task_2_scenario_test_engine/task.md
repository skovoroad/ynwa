# Проблема

В модуле ynwa-script-tests скрыта инфраструктура интеграционного тестирования. 
В настоящее время она реализована так: задаются тестовые команды, в которой у игроков задания составлены таким образом, чтобы спровоцировать известную игровую ситуацию. Например, игрок подбегает к мячу первым и отправляет мяч на угловой. После этого все игроки должны выполнить разумные действия: расположиться на позициях для углового.
После этого с помощью скрипта run_scenarios.sh тестовый скрипт запускает плеер, в котором проигрывается сценарий. Человек глазами отслеживает результат выполнения.

Такой подход имеет множество недостатков:
1. Отсутствие автоматизации. После чувствительных правок человек должен руками отследить все сценарии.
2. Ожидаемый результат не фиксирован. Человек может ошибиться в оценке полученного результата. 
3. Время исполнения. Плеер проигрывает сценарий с естественной скоростью, подходящей для просмотра человеком. Хотелось бы иметь возможность просчитать всю игру сразу, без задержек.
4. Малая комбинаторика. Автоматизированные прогон сценариев может дать возможность проверить самые различные комбинации событий.

# Предполагаемое решение:

Необходимо спроектировать возможность создания и проверки игровых сценариев, которые могут быть как проиграны в плеере, так и проверены автоматически.
Сценарии должны быть гранулярными и проверять конкретную ситуацию: поведение игрока при угловом, голе, фоле, правильное определение офсайда и проч. Наша цель - дать инструмент тестирования игровой логики УРОВНЯ ЯДРА. 

На входе:
- конфигурация команд 
- декларативно описанный ожидаемый результат: 
    - игровые события уровня (угловой, гол...)
    - положение игроков
    - решения игроков

На выходе: проверка прогона сценария. При этом сценарий по-прежнему может быть проигран в плеере.

Примеры: 
- сейчас нет определения офсайда, пример для будущего. Игроки расставлены в офсайдную позицию. У игрока задание: отдать пас игроку в неправильной позиции. Проверка: произошло событие "офсайд".
- угловой. игрок посылает мяч за лицевую линию. Проверка: игроки расставились по ожидаемым позициям, на мяч пошёл один игрок, который и должен был. Комбинаторика: своя/чужая лицевая линия, игроки команды А/Б, слева/справа от ворот.
