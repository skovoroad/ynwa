# О чём тут

Документ описывает возможности, которые должна предоставлять игра пользователю при составлении программных заданий для игроков
При этом документ не описывает конкретных деталей языка, в которых выражается эта возможность. 
Также приведены примеры тактик.
Документ не окончательный, используется при обсуждениях.

# Терминология

- Тактическая позиция - типовое положение на площадке (например, положение при розыгрыше углового)
- Тактическое задание игрока (сокр. тактика игрока) - программа игрока, заданная для определённое игровой ситуации. У игрока несколько тактических заданий, потому что есть несколько предопределённых игровых ситуаций. 
- Командное тактическое задание - тактика игрока, которая используется, если у игрока не задано индивидуальное задание. Определяется на уровне команды. Игрок может явно 
- Тактика - совокупность всех позиций и заданий

Мы должны различать пользователя игры (не называть его игроком) и игроков-футболистов, игровая абстракция (их называем игроками)

Мы не используем списки, циклы или контейнеры. Когда мы ниже используем выражение "список игроков", это означает, что проверка/действие по очереди используется для каждого игрока прямо в коде.

# Ограничения и ожидания  

Ограничения должны способствовать тому, чтобы при формировании тактик пользователь использовал игровые концепции, а не сложное программирование.

Примеры игровых концепций:
- свободный игрок
- свой игрок, чужой игрок
- игрок с мячом
- регион поля
- тактическая позиция
- отношения между позициями или регионами: ближе к воротам, дальше от ворот.

Неигровые концепции, их надо избегать:
- самостоятельное задание координаты на поле. Нельзя задать точную координату или читать компоненты координат напрямую — позицию можно только получить из функции стандартной библиотеки как непрозрачный объект.
- вычисление расстояний и базовая арифметика над ними допустимы только через функцию стандартной библиотеки (`distance(pos1, pos2)`) поверх непрозрачных позиций, без ручной координатной геометрии.
- анализ в цикле. Задание не должно перебирать игроков самостоятельно, а должно либо использовать прямые проверки для игроков через стандартные возможности ("игрок номер 1 свободен или игрок номер 2 свободен") либо функции стандартной библиотеки вроде подсчёта игроков в радиусе.

# Пример

Командное задание:
- если мяч у своей команды, игрок бежит в атакующую тактическую позицию
- если мяч у чужой команды: если я рядом с мячом - атаковать соперника с мячом, иначе бегу в оборонительную тактическую позицию.

Голкипер:
- без мяча смещаюсь так, чтобы быть между мячом и воротами (требует уточнения геометрии)
- с мячом - отдаю пас одному из заданного списка игроков

Крайние защитники:
- если мяч у меня, бегу с мячом до чужой штрафной (задаётся регионом) и отдаю свободному игроку из заданного списка, а если никто не свободен — ближайшему несвободному из того же списка
- иначе выполняю командное задание

Центральные защитники:
- если мяч у меня, отдаёт ближайшему свободному из заданного списка игроков, если они впереди; иначе бежит в атакующую тактическую позицию
- иначе выполняю командное задание

Крайние полузащитники:
- если мяч у меня, и впереди есть свободный игрок из заданного списка номеров, отдаю пас ему. Иначе бежать до штрафной и ударить по воротам.
- иначе выполняю командное задание

Центральные полузащитники:
- если мяч у меня
  - если впереди есть свободный игрок из заданного списка номеров, отдаю пас ему. 
  - если впереди есть свободный игрок из второго заданного списка номеров, отдаю пас ему. 
  - иначе бежать до штрафной и ударить по воротам.
- иначе выполняю командное задание

Нападающие:
- если мяч у меня, бежать до штрафной и ударить по воротам.
- иначе - общее поведение.

# Возможности анализа ситуации на поле

Из приведённой тактики мы можем выделить необходимые возможности:

Анализ позиции:
- определить игрока, владеющего мячом (`ball_owner_number()` и `get_ball_owner_team()`)
- определить, что я с мячом
- определить, что игрок ближе к воротам ("впереди"), чем я. Нужно сразу реализовать полный набор геометрических отношений (впереди, сзади, левее, правее) для своих и чужих игроков (`teammate_` / `opponent_`), а расстояния ("ближе"/"дальше") сравнивать через `distance`.
- определить команду, владеющую мячом (если отдан пас и мяч в полёте, считается, что команда ещё владеет мячом)
- игрок рядом с мячом с точностью до заданного расстояния (через `distance`)

Решение:
- бежать в тактическую позицию
- бежать в регион 
- бежать к мячу
- бежать в точно описанную координату (на первом этапе не нужно. Для вратаря временно используется отдельная стандартная функция, скрывающая детали)
- удар по воротам
- удар в заданную позицию (`kick_to_position`, например для паса в позицию игрока `teammate_position(number)`)
