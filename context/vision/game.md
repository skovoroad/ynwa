# О чём тут

Этот комплект документации представляет собой видение проекта разработчиком. Он не является документацией по проекту, а описывает целевое состояние. Полноценная документация расположена в спеках openspec. 

# Игра

Смысл игры: футбольный симулятор, в котором пользователь управляет командой, выдавая задания игрокам. Задания представляют собой программы на специально разработанном DSL, а также предопределённые переменные (например, типовые положения на площадке)
Содержание каждого такого задания: программа анализирует текущее положение на поле и игрок принимает решение о следующем своём действии.
Составив задания команде, пользователь наблюдает матч с соперником, анализирует действия игроков. 

# Текущее состояние

Реализовано ядро и клиент, позволяющие вести разработку игровой логики проекта. 
Разработаны стандартная библиотека на Lua и две демонстрационные тактики (папка teams). С игровой точки зрения они не несут ценности и должны быть расширены или заменены.
